# sandroamiridze.dev

My personal portfolio — security engineering, honeypots, and systems
programming in Rust and C.

Built with Astro, TypeScript, and Tailwind CSS, with a couple of React
islands for the interactive bits (the hero's role badge and the Aegis
lifecycle diagram).

## Running it locally

```bash
npm install
npm run dev      # http://localhost:4321
npm run build    # production build to dist/
```

Site copy and links live in `src/data/site.ts`.
